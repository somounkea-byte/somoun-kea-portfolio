## 💡 Key SEO Concepts Explained

### 1. Meta Description
- **What**: Short summary of your page (160 characters)
- **Why**: Appears in Google search results
- **Impact**: Affects click-through rate

### 2. Sitemap.xml
- **What**: XML file listing all pages
- **Why**: Helps Google discover and crawl pages faster
- **Impact**: Faster indexing (48 hours vs weeks)

### 3. Robots.txt
- **What**: Text file with crawler instructions
- **Why**: Controls which parts Google crawls
- **Impact**: Improves crawl efficiency

### 4. Structured Data (Schema)
- **What**: JSON-LD code that labels content
- **Why**: Helps Google understand your content
- **Impact**: Rich snippets in search results

### 5. Open Graph Tags
- **What**: Meta tags for social sharing
- **Why**: Makes posts look good on Facebook, LinkedIn
- **Impact**: More clicks from social media
